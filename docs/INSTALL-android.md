# نصب روی اندروید

## پیش‌نیاز
Android 6.0 (API 23) یا بالاتر · حدود ۵ مگابایت فضای خالی · دسترسی به میکروفون (اختیاری ولی توصیه‌شده)

## مراحل
1. فایل `SmartDriverAssistant-2.0.0.apk` را روی گوشی دانلود یا با کابل/واتساپ/Google Drive منتقل کنید.
2. با فایل‌منیجر روی APK بزنید.
3. پیام «نصب از این منبع مجاز نیست» → **Settings** → **Allow from this source** → برگشت → **Install**.
4. اگر Play Protect هشدار داد: **More details → Install anyway** (فایل با گواهی تجاری امضا نشده است).
5. اولین اجرا: اجازهٔ **میکروفون** و اجازهٔ **ذخیرهٔ فایل** را بدهید.

## فعال‌کردن صدای فارسی (فقط یک‌بار)
`Settings → General management → Language & input → Text-to-speech → Google TTS → Install voice data → فارسی`

## استفاده
- دکمهٔ **شروع گزارش صوتی** → دستیار سؤال می‌پرسد، شما جواب می‌دهید.
- پس از پایان: **گزارش** را ببینید، **کپی** کنید یا با **واتساپ** برای مدیر بفرستید.
- در تب **آمار**، روند شیفت و شاخص‌ها را ببینید.
- **خروجی اکسل برای مدیر** → فایل `gozaresh-<نام>-<تاریخ>.xlsx` در `Downloads` ذخیره و قابل اشتراک می‌شود.

## رفع اشکال
| مشکل | راه‌حل |
|---|---|
| «App not installed» | نسخهٔ قبلی با همین بسته را حذف کنید و دوباره نصب کنید |
| صدا خوانده نمی‌شود | بستهٔ صدای فارسی TTS را نصب کنید؛ در تنظیمات برنامه «خواندن سؤال‌ها» روشن باشد |
| میکروفون کار نمی‌کند | اجازهٔ میکروفون + نصب Google Speech Services |
| اکسل ذخیره نمی‌شود | در اندروید ۱۰+ اجازهٔ فایل لازم نیست؛ در نسخه‌های قدیمی‌تر اجازهٔ Storage بدهید |
