## 🎙️ گزارش گفت‌وگویی (قلب نسخهٔ ۲)

دکمهٔ «گزارش گفت‌وگویی» یک مصاحبهٔ صوتی ۱۳ مرحله‌ای است:

| # | سؤال | نوع پاسخ |
|---|---|---|
| ۱ | اسم و نام خانوادگی | متن (یا «همان» برای مقدار قبلی) |
| ۲ | پلاک خودرو | متن |
| ۳–۴ | کیلومتر شروع / پایان | عدد |
| ۵ | مسافت (یا «خودکار») | عدد / خودکار از کیلومترها |
| ۶–۹ | سوخت مصرفی، بارگیری، تعداد خودرو، تعداد سفر | عدد |
| ۱۰ | کارهای انجام‌شده | جملهٔ آزاد (پایان با «تمام») |
| ۱۱ | مشکلات و خرابی | متن («ندارم») |
| ۱۲ | توضیحات | متن («رد کن») |
| ۱۳ | تأیید نهایی | «بله» → ثبت گزارش + ساخت اکسل |

- دستیار هر سؤال را با **TTS فارسی** بلند می‌خواند (`خواندن سؤال‌ها با صدا`).
- در حالت **هندزفری**، پس از پایان خواندن سؤال، میکروفون خودکار فعال می‌شود؛ راننده فقط صحبت می‌کند.
- متن زندهٔ پاسخ روی صفحه نمایش داده می‌شود و دکمه‌های «تکرار سؤال»، «رد کردن»، «سؤال قبلی» و «پایان گفت‌وگو» همیشه در دسترس‌اند.
- پاسخ‌ها با NLU فارسی درک می‌شوند: اعداد فارسی/عربی/لاتین و اعداد نوشتاری («دویست و پنجاه»)، عبارت‌های «ندارم»، «خودکار»، «همان».

## 📊 خروجی اکسل (ساخته‌شده روی گوشی)

فایل `.xlsx` واقعی و چندبرگی، بدون هیچ کتابخانهٔ بیرونی (OOXML + ZIP + CRC32 در `xlsx.js`):

1. **خلاصه شیفت** — مشخصات راننده/خودرو، جدول ۱۱ شاخص با هدف و وضعیت، و تحلیل هوشمند.
2. **گزارش روز** — فرم کامل به‌همراه جای امضای راننده و تأیید مدیر.
3. **تاریخچه** — همهٔ گزارش‌های ثبت‌شده، ستون‌بندی‌شده + سطر جمع کل.

فایل در پوشهٔ `Downloads` ذخیره و **بلافاصله پنجرهٔ ارسال** (واتساپ/ایمیل/بلوتوث) باز می‌شود تا برای مدیر فرستاده شود.
در تنظیمات می‌توانید شمارهٔ واتساپ مدیر را وارد کنید تا ارسال متنی هم یک‌کلیکی شود.

## 📱 نصب APK

1. فایل `SmartDriverAssistant-2.0.0.apk` را روی گوشی باز کنید و اجازهٔ نصب از منبع ناشناس را بدهید.
2. اولین بار که میکروفون را بزنید، اجازهٔ ضبط صدا را بدهید.
3. برای گفتار فارسی مطمئن شوید بستهٔ زبان فارسی موتور Google نصب است
   (تنظیمات → سیستم → زبان و ورودی → ورودی صدا / تبدیل متن به گفتار).
   برای کار **کاملاً آفلاین**، زبان فارسی را در موتور تبدیل گفتار به متن **آفلاین** دانلود کنید.
4. کلید امضا: `keystore.jks` — رمز `driver1405`، alias `smartdriver`.

> بدون بستهٔ آفلاین، تشخیص گفتار به اینترنت نیاز دارد ولی **بقیهٔ برنامه** (فرم، محاسبات، اکسل، تاریخچه) کاملاً آفلاین است.

## 🛠 ساخت مجدد

```bash
cd driver-assistant && ./build.sh          # APK  → out/
python3 make_preview.py                    # نسخهٔ تک‌فایل HTML
cd ../webapp && npm install && npm run build   # نسخهٔ وب Next.js
```

`build.sh` بدون Gradle: `aapt2 → javac → d8 → zipalign → apksigner` (به Android SDK 34 و JDK 17 نیاز دارد).

### پل بومی (Native bridge)

| متد | کارکرد |
|---|---|
| `Android.startListening(continuous)` / `stopListening()` | تشخیص گفتار زندهٔ اندروید (`SpeechRecognizer`، بدون پنجرهٔ مزاحم) با نتایج جزئی |
| `Android.speak(text)` → رویداد `window.__onSpeakDone` | خواندن سؤال‌ها و پاسخ‌ها با TTS فارسی + اعلام پایان گفتار |
| `Android.saveExcel(base64, name)` | ساخت فایل در Downloads و باز کردن پنجرهٔ ارسال |
| `Android.saveFile`, `share`, `whatsappTo`, `vibrate`, `toast` | فایل متنی، اشتراک‌گذاری، واتساپ مدیر، بازخورد لمسی |
| `window.__back()` | مدیریت دکمهٔ بازگشت |

## 🌐 تلفیق با پروژهٔ Next.js شما

`webapp/` قالب `nextjs-postgresql-template` (Next 16.2.6، React 19، Tailwind 4، Drizzle) را نگه داشته و
اپلیکیشن را روی آن سوار کرده است:

- `src/app/page.tsx` پوستهٔ مشترک را بارگذاری و موتور را اجرا می‌کند (همان فایل‌های `public/app/`)
- `src/app/globals.css` = Tailwind + استایل اپلیکیشن
- `src/db/schema.ts` و `src/app/api/reports/route.ts` برای همگام‌سازی **اختیاری** گزارش‌ها (بدون دیتابیس هم همه‌چیز کار می‌کند)
- `npm run build` با موفقیت تست شده است. برای انتشار: `npx vercel` یا اتصال ریپو به Vercel.
