# راننده هوشمند — نسخهٔ وب (Next.js)

این پروژه، تلفیق قالب `nextjs-postgresql-template` با اپلیکیشن «راننده هوشمند» است.
رابط کاربری و موتور هوشمند همان فایل‌های داخل APK اندروید هستند
(`public/app/shell.html` + `public/app/app.js` + `public/app/xlsx.js`)، بنابراین نسخهٔ وب و اپلیکیشن
دقیقاً یک رفتار دارند و همهٔ محاسبات/گزارش‌ها روی خود دستگاه انجام می‌شود.

## اجرا

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
```

## ساختار

```
src/app/layout.tsx        چیدمان راست‌به‌چپ + متادیتا + فونت
src/app/page.tsx          میزبان اپلیکیشن (بارگذاری پوسته و موتور)
src/app/globals.css       Tailwind + استایل اپلیکیشن (app.css)
src/db/schema.ts          اسکیمای اختیاری Drizzle برای همگام‌سازی گزارش‌ها
src/app/api/reports/      API اختیاری (بدون DATABASE_URL خاموش می‌ماند)
public/app/               فایل‌های مشترک با APK (پوسته، موتور، اکسل، فونت، آیکون)
```

## نکتهٔ مهم دربارهٔ آفلاین بودن

نسخهٔ اندروید (APK) تمام فایل‌ها را درون خود دارد و **بدون اینترنت و سرور** کار می‌کند.
نسخهٔ وب هم پس از اولین بارگذاری، بدون سرور کار می‌کند (PWA + localStorage)؛ دیتابیس پستگرس
فقط یک قابلیت اختیاری برای داشبورد مدیر است و نبودش هیچ چیزی را خراب نمی‌کند.
